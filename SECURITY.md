# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Report it privately to
the security owners listed in `.github/CODEOWNERS` with the affected URL or file,
reproduction steps, impact, and any suggested mitigation.

We will acknowledge reports within five business days and provide a remediation
timeline after triage. Please avoid accessing or modifying data belonging to
other users while validating a report.

## Supported versions

Only the deployed production version and the current default branch receive
security fixes. Dependencies are reviewed weekly through Dependabot and CI.
